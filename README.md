**Main Controller Overview**

The Main Controller is a critical component of the Garden Automation System, responsible for receiving and processing data from Measuring Nodes, controlling Watering Nodes, and monitoring system status.

## Main Controller Components

* Raspberry pi Pico 2 W
* Solar panel with charge controller
* Battery backup (car battery) to ensure power supply during night hours

## Main Controller Functionality

1. **Communication with Measuring Nodes**: The Main Controller communicates with Measuring Nodes using WiFi to receive soil moisture readings.
2. **Control of Watering Nodes**: The Main Controller controls Watering Nodes based on received data from Measuring Nodes, ensuring precise watering for each zone.
3. **System Monitoring and Control**: The Main Controller monitors system status, including battery level, solar panel efficiency, and node connectivity.
